At what time is electricity the cleanest?

To answer this question I have created a streamlit app based on the data from https://odre.opendatasoft.com/explore/dataset/eco2mix-national-cons-def/ which will hopefully help answer this question. 

To launch Streamlit:
pip install -r requirements.txt
streamlit run app.py
Then click on url

Structure
- app.py : Data, Graph 1, Graph 2, Graph 3, Graph 4, Limitations, Conclusion
- data.py : Download, check for problems and cleaning

Data :
RTE – éCO₂mix national, data.gouv.fr / ODRÉ, Licence Ouverte Etalab 2.0.
Lien : https://odre.opendatasoft.com/explore/dataset/eco2mix-national-cons-def/
